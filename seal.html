Tentang

Sealed Message

Kirim rahasia lewat link yang cuma bisa dibuka penerima.

Pesan dienkripsi AES-256-GCM di browsermu. Hasilnya ada di bagian # link, yang tidak pernah dikirim browser ke server mana pun.

Cara pakai4 langkah
  1. 1
    Tulis pesan

    Misalnya password WiFi atau kredensial akun tim. Maksimal 4.000 karakter.

  2. 2
    Pilih cara membuka

    Link saja: praktis, siapa pun yang punya link bisa membuka. Link + passphrase: lebih aman, kirim passphrase lewat jalur lain.

  3. 3
    Tekan Segel pesan

    Salin link, tampilkan QR, atau salin blok armored bila chat memotong link.

  4. 4
    Kirim ke penerima

    Penerima membuka link (atau menempel blok armored) di halaman Buka pesan.

Link hanya bisa dibuka penerima bila situs ini di-hosting (misal GitHub Pages). Untuk sekarang, kirim blok armored.
