File Locker

Kunci file dengan AES-256, langsung di browser.

Scan KTP, transkrip, kontrak. File dienkripsi lokal jadi .ewall, nama aslinya ikut disembunyikan. Tidak ada yang diunggah.

Cara pakai4 langkah
  1. 1
    Pilih file

    Di tab Kunci file, tarik file ke kotak atau tekan Pilih file. Boleh banyak sekaligus.

  2. 2
    Buat passphrase

    Minimal 12 karakter, atau tekan "Buat passphrase kuat". Simpan passphrase-nya: tanpa itu file tidak bisa dibuka.

  3. 3
    Tekan Kunci file

    File .ewall terunduh dengan nama acak. Nama asli tersimpan di dalam file terenkripsi.

  4. 4
    Membuka kembali

    Di tab Buka file, pilih file .ewall, masukkan passphrase, lalu unduh file aslinya.

File yang dikunci

    Boleh banyak file sekaligus; tiap file jadi .ewall sendiri. Batas 200 MB per file.

      Kalau situs ini hilang?

      Format .ewall terbuka dan terdokumentasi. File tetap bisa dibuka offline dengan Python CLI yang ikut di folder proyek:

      python python/ewall_cli.py decrypt locked-7f3a9c12.ewall
