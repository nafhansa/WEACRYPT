Integrity Checker

Pastikan file unduhan tidak dimodifikasi.

Hitung hash file ISO, installer, atau dokumen di browsermu, lalu cocokkan dengan hash yang dipublikasikan pembuatnya. File tidak diunggah.

Cara pakai4 langkah
  1. 1
    Pilih algoritma

    Biasanya SHA-256. Pakai yang sama dengan yang tertulis di situs resmi.

  2. 2
    Pilih file

    Di tab File, tarik file yang kamu unduh. File tidak diunggah ke mana pun.

  3. 3
    Tempel hash resmi

    Salin hash dari situs pembuat ke kolom "Hash yang diharapkan".

  4. 4
    Baca hasilnya

    Cocok berarti file asli. Tidak cocok berarti berbeda: jangan pakai file itu dan unduh ulang dari sumber resmi.
