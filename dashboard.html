Control Room

Langit Bandung, kesehatan entropi, dan aktivitasmu dalam satu layar.

Cara pakai4 langkah
  1. 1
    Baca langit Bandung

    Sky Feed menampilkan cuaca live dari OpenWeatherMap. Tekan "Lihat JSON mentah" untuk melihat respons asli API.

  2. 2
    Aduk entropi

    Gerakkan mouse atau jari di kotak Entropy Pool. Gerakanmu ikut dicampur, tapi keamanan tetap datang dari cincin dalam (256 bit dari sistem operasi).

  3. 3
    Buat password sekali klik

    Quick Forge membuat password 20 karakter. Hasilnya tersembunyi: tekan Tampilkan untuk melihat atau Salin untuk menyalin.

  4. 4
    Pantau aktivitas

    Ledger mencatat setiap aktivitas tanpa menyimpan rahasianya. Centang Security checklist untuk melacak kebiasaan aman.
