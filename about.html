Nama WEACRYPT

WEAther enCRYPTion: enkripsi yang hidup bersama cuaca. Setiap password, pesan tersegel, file terkunci, dan blok ledger membawa stempel langit Bandung saat ia dibuat. Tapi seperti dijelaskan di bawah, cuaca hanya memberi identitas. Yang menjaga keamanan selalu matematika.

Kenapa cuaca tidak dipakai sebagai rahasia

Ide awal proyek ini adalah menurunkan kunci kriptografi dari data cuaca. Ide itu rusak, dan WEACRYPT sengaja dibangun di atas koreksinya:

  1. Data OpenWeatherMap itu publik. Siapa pun yang tahu kota dan kira-kira jamnya bisa memanggil endpoint yang sama dan mendapat angka yang sama.
  2. Resolusinya rendah dan jarang berubah. Tanpa API pun ruang kemungkinannya sekitar 248, jebol dalam hitungan jam dengan GPU. Lihat buktinya di Attack Lab.
  3. Cloudflare LavaRand bukan bukti sebaliknya. LavaRand memakai noise kamera yang privat, dan hasilnya hanya salah satu input tambahan yang dicampur dengan entropi OS. Kalau kamera mati, sistem tetap aman karena entropi OS.

Jadi di sini cuaca dipakai untuk visual dan identitas, sebagai pencampur tambahan, sebagai stempel konteks di setiap artefak, dan sebagai bahan edukasi. Keamanan selalu bersandar pada CSPRNG browser dan algoritma standar: AES-GCM, PBKDF2, HKDF, SHA-256, dan Shamir.

Cara kerja mixer

ikm = osSeed(32) || SHA-256(cuaca) || SHA-256(jitter)
out = HKDF-SHA256(ikm, salt = random(16), info = "EW/v1/" + purpose)

Karakter dipilih dengan rejection sampling, jadi tidak ada bias modulo. Setelah dipakai, buffer seed diisi nol sebisanya.

Model ancaman

Dilindungi

  • Penyadapan jaringan: rahasia tidak pernah dikirim.
  • Server bocor: tidak ada server kami yang menyimpan apa pun.
  • Link Sealed Message tercegat, untuk mode link + passphrase.
  • File .ewall dicuri tanpa passphrase.
  • Satu share Shamir dicuri (selama di bawah ambang k).

Tidak dilindungi

  • Perangkat terinfeksi malware atau keylogger.
  • Penerima pesan yang tidak bisa dipercaya.
  • Screenshot, kamera, atau orang di belakangmu.
  • Link mode "link saja" yang jatuh ke orang lain.
  • Passphrase lemah atau dipakai ulang.

Ke mana data pergi

Yang keluar dari browsermu cuma dua: nama kota ke layanan cuaca, dan 5 karakter hash ke layanan cek kebocoran. Buka DevTools, tab Network, lalu pakai alat apa pun untuk membuktikannya.

Content-Security-Policy di setiap halaman membatasi connect-src ke dua API itu saja. Ledger dan checklist disimpan di localStorage karena tidak berisi rahasia; cache cuaca di sessionStorage. Password, kunci, pesan, dan share hanya hidup di memori tab.

Inspirasi: Cloudflare LavaRand

Di lobi kantor Cloudflare ada dinding sekitar seratus lava lamp yang direkam kamera. Noise piksel dari video itu di-hash dan dicampur ke pool entropi bersama sumber acak sistem operasi. Kuncinya: video itu privat, dan ia hanya satu dari beberapa input. WEACRYPT meminjam gagasan "alam sebagai sumber acak", tapi mengganti kamera privat dengan langit Bandung yang publik, dan karena itu tidak pernah menghitungnya sebagai keamanan.

Menjalankan lokal

Buka index.html langsung, atau jalankan server lokal agar semua fitur (termasuk link Sealed Message) bekerja:

python -m http.server 8000
# lalu buka http://localhost:8000

API key OpenWeatherMap diatur di js/config.js. Tanpa key, alat tetap bekerja penuh dan visual memakai snapshot.

Python CLI (opsional, untuk resiliensi)

Kalau situs ini hilang, data tetap bisa dipulihkan secara offline:

pip install -r python/requirements.txt
python python/ewall_cli.py decrypt locked-7f3a9c12.ewall
python python/ewall_cli.py encrypt dokumen.pdf
python python/ewall_cli.py shamir-combine share1.txt share2.txt share3.txt
python python/ewall_cli.py verify-ledger ledger-export.json
python python/ewall_cli.py selftest

Self-test browser: buka about.html?selftest=1.

Pertanyaan umum

Apakah cuaca bikin password lebih aman?

Tidak. Data cuaca itu publik: siapa pun bisa mengambil angka yang sama dari OpenWeatherMap, dan tanpa API pun ruang kemungkinannya cuma sekitar 248. Keamanan datang dari 256 bit crypto.getRandomValues(). Cuaca hanya membuat setiap hasil unik dan diberi stempel. Buktinya ada di Attack Lab.

Ke mana data saya pergi?

Tidak ke mana-mana. Semua enkripsi, hashing, dan pembuatan kunci terjadi di browsermu. Yang keluar hanya nama kota ke OpenWeatherMap dan 5 karakter pertama hash SHA-1 ke Pwned Passwords saat kamu mengecek kebocoran.

Bisa dipakai offline?

Ya untuk hampir semua alat setelah halaman termuat. Cuaca memakai snapshot terakhir, dan Breach Radar memang butuh koneksi.

Kalau situs ini hilang, file terenkripsi saya bagaimana?

Format .ewall dan share Shamir terdokumentasi, dan proyek ini membawa Python CLI (python/ewall_cli.py) yang bisa membuka file dan menggabungkan share secara offline.
