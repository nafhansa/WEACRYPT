Gulir

Apa itu WEACRYPT

Alat keamanan pribadi yang hidup bersama langit.

  1. 1

    Langit jadi sinyal

    WEACRYPT membaca cuaca Bandung secara live dari OpenWeatherMap. Data ini publik, jadi dipakai sebagai warna, identitas, dan stempel di setiap hasil.

  2. 2

    Matematika jadi pengaman

    Keamanan selalu datang dari 256 bit acak sistem operasi dan algoritma standar: AES-256, PBKDF2, SHA-256, Shamir. Cuaca hanya ikut dicampur, tidak pernah jadi rahasia.

  3. 3

    Semua terjadi di browsermu

    Tanpa akun, tanpa server, tanpa database. Password, pesan, dan file tidak pernah meninggalkan perangkatmu.

Fitur

        
Delapan alat. Satu browser.

        
Setiap halaman punya panduan "Cara pakai" langkah demi langkah.

      

      

        
          
          
Key Forge

          
Buat password, passphrase, PIN, dan kunci kriptografi.

          
Manfaat: tidak perlu lagi memakai ulang password lemah. Kamu tahu persis seberapa kuat hasilnya.

          Buka Key Forge
        
        
          
          
Breach Radar

          
Cek apakah password pernah bocor di kebocoran data.

          
Manfaat: tahu password mana yang harus diganti, tanpa pernah mengirim password-nya.

          Buka Breach Radar
        
        
          
          
Sealed Message

          
Ubah pesan rahasia jadi link terenkripsi.

          
Manfaat: kirim password WiFi atau kredensial tim lewat chat tanpa plaintext.

          Buka Sealed Message
        
        
          
          
File Locker

          
Kunci file apa pun dengan AES-256 langsung di browser.

          
Manfaat: scan KTP, transkrip, atau kontrak aman walau file-nya tercecer.

          Buka File Locker
        
        
          
          
Secret Splitter

          
Pecah seed phrase jadi beberapa bagian.

          
Manfaat: satu kertas hilang atau dicuri tidak lagi berarti dompetmu hilang.

          Buka Secret Splitter
        
        
          
          
Integrity Checker

          
Hitung dan cocokkan hash file unduhan.

          
Manfaat: pastikan installer atau ISO yang kamu unduh tidak dimodifikasi.

          Buka Integrity Checker
        
        
          
          
Entropy Ledger

          
Catatan aktivitas berantai dengan proof-of-work.

          
Manfaat: lihat sendiri bagaimana blockchain mendeteksi data yang diubah.

          Buka Entropy Ledger
        
        
          
          
Attack Lab

          
Serangan nyata terhadap kunci yang lemah.

          
Manfaat: paham kenapa "acak" itu penting, dan kenapa cuaca saja tidak cukup.

          Buka Attack Lab
